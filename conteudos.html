1. Fundamentos da Programação

Lógica da Programação

Lógica da programação é a capacidade de organizar instruções para resolver um problema.

Algoritmo

Um Algoritmo é uma sequencia de passos para realizar uma tarefa ou solucionar um problema.

Pensamento Computcional

É uma forma de resolver problemas utilizando conceitos presentes na computação.

  • Decomposição
  • Reconhecimento de padrôes
  • abstração
  • algoritmos

2. O que é um computador?

Um computador é uma maquina capaz de receber, processar, armazenar e produzir informações.

Input

Dados que entram no sistema.

Output

Informações produzidas pelo sistema.

Frontend

Parte da aplicação com a qual o usuario interage

Backend

Parte responsavel pela lógica e processsamento no servidor.

Memória

Área utilizada para armazenar temporariamente ou permanentemente informações.

2. Fluxogramas

Fluxogramas representam visualmente os passos de um algoritmo

Principais elementos

  • Início/fim
  • Processo
  • Entrada/Saída
  • Decisão
  • Setas de fluxo

Onde criar?

Você pode criar fluxogramas usando ferramentas como: digramas.net, Lucidchart ou outras ferramentas de diagramas.

6. Estruturas Condicionais

if, elif e else

          idade = 18
          
          if idade >= 18:
           print("Maior de Idade")
          elif idade == 17:
           print("Quase 18")
          else:
           print("Menor de Idade")

Match/case

opcao = 2

match opcao:
    case 1:
        print("Início")
    case 2:
        print("Configurações")
    case 3:
        print("Sair")

7. Estruturas de repetição

while

contador = 0

while contador < 5:
    print(contador)
    contador += 1

for

for numero in range(5):
    print(numero)
